git fetch -all 
- Scarica tutti gli aggiornamenti da tutti i repository remoti collegati al tuo progetto
- Ricevi gli aggiornamenti, ma non li pubblichi ancora sul tuo locale.

git checkout -B master origin/master --force
 - git checkout	//Comando base per cambiare ramo o ripristinare file.
 - -B (maiuscolo): Crea un nuovo ramo o resetta un ramo esistente se già presente.
 - Nome del ramo su cui operare.
 - origin/master: Punto di partenza (il ramo master su GitHub).
 - --force: Forza l'operazione ignorando avvertimenti e conflitti.

 git clean -fd
  - clean: Rimuove file non tracciati
  - -f (force): Obbligatorio per eseguire l'operazione (senza non funziona)
  - -d: Rimuove anche le directory non tracciate
  - -n  Mostra cosa verrebbe cancellato SENZA eseguire

 git branch -a
  - branch: Mostra l'elenco dei rami
  - -a (all): Mostra sia i rami locali che quelli remoti
